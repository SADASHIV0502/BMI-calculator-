# BMI Calculator

A simple Python-based Body Mass Index (BMI) Calculator developed in Google Colab as part of the **Oasis Infobyte** internship.

## Overview

This BMI Calculator allows users to input their weight and height, then calculates their BMI and classifies it into categories such as underweight, normal weight, overweight, and obesity. It serves as a practical demonstration of Python programming for real-world applications.

## Features

- **User Input Handling:** Accepts weight in kilograms and height in meters.
- **BMI Calculation:** Computes BMI using the formula: `BMI = weight / (height ** 2)`.
- **Categorization:** Provides BMI categories based on the calculated BMI value.
- **Interactive Environment:** Designed to run in Google Colab for easy interaction.

## Requirements

- Python 3.x
- Google Colab (for running the notebook)

## Usage

1. Clone this repository or download the `bmi_calculator.ipynb` notebook.
2. Open the notebook in [Google Colab](https://colab.research.google.com/).
3. Run the cells to execute the code.
4. Enter your weight and height when prompted to get your BMI and its category.
